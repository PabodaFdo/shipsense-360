# Data Sources

Download version 5 of the DataCo SMART SUPPLY CHAIN dataset:
https://data.mendeley.com/datasets/8gx2fvg2k6/5

DOI: 10.17632/8gx2fvg2k6.5

Place these two files in `data/raw/`:

- `DataCoSupplyChainDataset.csv`
- `DescriptionDataCoSupplyChain.csv`

Git ignores `data/raw/`. This README tells anyone who clones the project
where to get the files and where to put them.
