# ShipSense 360 User Stories

## US-01 · Compare shipping modes

As a fulfilment manager, I want to compare late-shipping rates
across shipping modes so I can decide which mode to investigate first.

Related requirements: BR-01 and FR-01.

## US-02 · Check a new order’s shipping risk

As a fulfilment manager, I want to see the chance that a new order
will ship late so I can decide whether my team should review it
before shipment.

Related requirements: BR-02 and FR-02.
